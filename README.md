# IT Asset Tracker

A web-based IT asset management system built with PHP, MySQL, HTML and CSS.

## Overview

The IT Asset Tracker helps organizations record, manage and monitor their IT equipment from one place.

## Planned Features

- Add and view IT assets
- Record asset names, categories, serial numbers and locations
- Track assigned users and asset status
- Update and delete asset records
- Record maintenance and repair history
- Search and filter the inventory

## Technologies

- HTML5
- CSS3
- PHP
- MySQL
- Git and GitHub

🚧 In development

This project demonstrates practical skills in IT asset management, database design, web development and troubleshooting.
